# QuickBite Admin Flow

Responsive food-delivery platform admin console built with React, Vite, React Router, Recharts and Lucide icons.

## Run
```bash
npm install
npm run dev
```
Open the URL Vite prints (usually http://localhost:5173).

## Build
```bash
npm run build
npm run preview
```

Includes Dashboard & Analytics, Order Management, Restaurant & Menu Management, Delivery Partner Management, Customer Management, Payments & Finance, Offers & Promotions, and Support/Reports/Settings. Uses mock data and local browser state; integrate authenticated APIs before production. Financial actions and live tracking are demo-only.
